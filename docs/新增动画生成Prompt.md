# 新增小二哈动画生成 Prompt

现有动画：待机、吃饭、开心、睡觉、饥饿、口渴、喝水、困倦、想陪伴、被抚摸。本批优先丰富自定义商品的动作，再补奖励反馈与日常动作。

| 批次 | 动作 | 资源名称 | 播放方式 |
| --- | --- | --- | --- |
| 第一批 | 玩球 | play | 短循环，结束后由程序切换 |
| 第一批 | 洗澡 | bath | 短循环，结束后由程序切换 |
| 第一批 | 吃零食 | treat | 短循环，结束后由程序切换 |
| 第二批 | 试穿衣服 | dress | 单次试穿展示 |
| 第二批 | 任务完成庆祝 | achievement | 单次奖励反馈 |
| 第三批 | 伸懒腰 | stretch | 一次完整动作 |

每次上传当前小二哈图片作为角色参考，将下面的通用要求和一个动作段一起发送给图片 AI。一个动作单独生成一张图，不混合多种动作。

## 通用要求

```text
请严格参考我上传的小二哈图片，绘制同一只哈士奇的游戏动画精灵表。

保持参考图的画风、灰白毛色、脸部花纹、眼睛颜色、耳朵形状、头身比例、描边粗细和光照一致，不重新设计角色。面向方向与参考图一致，固定相机、固定视角，无镜头运动。

输出一张 2048×512 像素、横向 4 帧的 RGBA PNG 精灵表，4 个单元格各为 512×512 像素，从左到右严格按动画时间排列，不画格线。如果不能精确输出尺寸，也必须保持 4:1 画布比例、四帧等宽。

背景必须是真正的透明 Alpha，不要把透明棋盘格画进图片，也不要白底、色底、渐变背景、地板或投影。不要文字、数字、状态名称、帧序号、标志、水印或 UI 元素。

四帧采用同一个角色比例和对齐基准。地面基准线固定在每格下方约 440 像素处，不画出这条线。角色和道具应完整位于各自单元格，四周至少留 48 像素透明边距。不要任何内容跨格、贴边或被切断，不要邻格残影、运动拖影或多余身体部位。

动作变化清晰但幅度克制，以便缩小到约 140×132 像素时仍可辨认。不要密集细节、细小文字、大量粒子或大面积透明光效。循环动作的第四帧应自然衔接第一帧；单次动作按准备、执行、完成的顺序设计。

下面指定的动作之外，不要混入其他状态，也不要在动作最后擅自插入另一个开心、睡觉、饥饿或口渴动作。
```

## 第一批：玩球 play

```text
本组动作：小二哈与一颗橙色小球玩耍，温和、活泼，适用于购买玩具或游戏互动。

第1帧：小二哈看向前爪旁的橙色小球，身体稳定，尾巴轻轻向一侧摆。
第2帧：抬起一只前爪，轻碰小球，小球向侧面移动一点。
第3帧：前爪收回，小球轻轻弹回附近，耳朵略微抬起，尾巴摆向另一侧。
第4帧：小球回到接近第1帧的位置，小二哈恢复准备玩球的姿势。

小球的颜色、大小和材质四帧一致。角色不跑出画面，不大跳跃，不翻滚，不出现第二只狗。四帧只表现玩球，不接额外庆祝动作，可首尾循环。
```

## 第一批：洗澡 bath

```text
本组动作：小二哈在一个浅蓝色小浴盆里洗泡泡澡。浴盆小巧，能看清小二哈的脸、耳朵和前爪，角色不被泡沫遮住。

第1帧：小二哈安静坐在浴盆中，头顶和胸前有少量简洁的白色泡泡，眼神放松。
第2帧：小二哈轻轻闭眼，一只前爪抬到胸前，头顶泡泡略微改变形状。
第3帧：小二哈睁开眼睛，前爪轻轻放下，旁边出现两三个小水滴。
第4帧：恢复接近第1帧的姿势，泡泡与水滴归于平静。

四帧保持浴盆和身体位置稳定。不要大量喷水、满屏泡沫、夸张甩动、湿毛变形或浴室背景。只表现洗澡动作，不接额外开心庆祝，可首尾循环。
```

## 第一批：吃零食 treat

```text
本组动作：小二哈吃一小块浅金色、骨头形状的宠物饼干。不要食盆，视觉上与已有吃饭动作区分。

第1帧：小二哈低头看向两只前爪间的小饼干，眼神期待。
第2帧：把饼干凑近嘴边，轻轻咬一口，头部只有小幅度移动。
第3帧：嘴巴轻轻咀嚼，脸颊略微变化，旁边只有一两粒饼干屑。
第4帧：恢复接近第1帧的准备姿势，嘴边干净，继续自然的小幅咀嚼节奏。

饼干在四帧中保持接近一致的尺寸，不表现逐帧永久消失，以便连续播放。不要满屏食物、额外金币、道具文字、大幅摇头或庆祝跳跃。四帧只表现吃零食，可首尾循环。
```

## 第二批：试穿衣服 dress

```text
本组动作：同一只小二哈试穿一件简洁的浅绿色小背心，衣服不带文字和图案，始终露出原有脸部花纹、耳朵、前爪和尾巴。

第1帧：小二哈保持参考图的自然姿势，尚未穿背心，浅绿色背心整齐放在前爪旁。
第2帧：小二哈轻微低头，背心已套到身体上，前爪轻轻调整衣服边缘，动作自然可爱。
第3帧：背心穿好，小二哈稍稍挺起胸口，展示衣服，尾巴轻摆。
第4帧：保持穿好背心后的放松姿势，表情满足，方便程序短暂停留。

这是一段单次试穿动画，不需要首尾循环。背心颜色和款式一致，不要改变狗的身体比例，不站成人类姿势，不画手臂、镜子、衣架或房间。
```

本组按短暂试穿展示设计。若要购买后一直穿着，需要为待机、吃饭、喝水、睡觉等动作补同款服装版本，或另行设计可叠加的服装图层。

## 第二批：任务完成庆祝 achievement

```text
本组动作：小二哈在孩子完成学习任务、获得奖励时给予短暂鼓励。与普通开心动作区分，增加一枚没有文字、数字或货币符号的小金色奖章和少量星星。

第1帧：小二哈自然坐好，抬头看向前方，眼神期待。
第2帧：抬起一只前爪，胸前出现一枚小金色奖章，两侧出现两颗简洁星星。
第3帧：小二哈挺起胸口，露出鼓励的笑容，尾巴轻摆，奖章清晰可见。
第4帧：前爪放下，保持满足而温和的笑容，星星消失，奖章仍短暂保留。

这是一段单次奖励动画，不需要首尾循环。不要金币雨、烟花、文字横幅、巨大跳跃或复杂特效。奖章与星星不得遮挡脸部，角色保持在原来的位置。
```

## 第三批：伸懒腰 stretch

```text
本组动作：小二哈休息后轻轻伸一个懒腰，作为日常生活小动作。不要在睡眠姿势中反复抖动身体，也不要把伸懒腰混成睡觉循环。

第1帧：小二哈恢复清醒，保持稳定的自然姿势。
第2帧：两只前爪稍向前伸，头部略微降低，背部轻轻舒展。
第3帧：保持轻柔的伸展姿势，眼睛微眯，尾巴自然弯曲，幅度不夸张。
第4帧：收回前爪，回到与第1帧接近的自然姿势。

动作是一次完整的舒展过程，身体比例、角色位置和地面基准保持一致。不要夸张拉长四肢、瑜伽姿势、大幅度躯干扭动、睡眠符号、文字或背景。
```

## 交付素材

每个动作独立交付 PNG。建议文件名为 `play.png`、`bath.png`、`treat.png`、`dress.png`、`achievement.png`、`stretch.png`。如果图片 AI 支持批量独立导出，也可输出各动作的 `动作_01.png` 到 `动作_04.png`，每张 512×512、透明背景、同一对齐基准。

后续接入时先检查透明通道和四格边界，再按整组统一裁剪、缩放和压缩，避免每帧单独紧裁导致身体忽大忽小或上下跳动。生成这些素材本身不会自动增加设备动作或商品选项，接入时再扩展动作映射。
