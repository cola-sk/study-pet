# ESP32-S3 开发环境安装（macOS）

当前电脑检查结果：Apple Silicon（arm64）、macOS 15.1，已发现 Homebrew、Python 3 和 Xcode 开发工具。以下由你自行操作。使用乐鑫官方 ESP-IDF 和已购微雪 ESP32-S3-Touch-LCD-2.8 验证。先检查开发板背面标签是 V1 还是 V2；两版触摸芯片和示例不同。

## 1. 检查基础工具

打开终端执行：

```bash
xcode-select -p
brew --version
git --version
python3 --version
```

如果 `xcode-select -p` 报错，运行 `xcode-select --install` 并按提示完成安装。Homebrew 未安装时参考 [Homebrew 官方说明](https://brew.sh/)；当前电脑已检测到 Homebrew。安装常用工具：

```bash
brew install cmake ninja ccache dfu-util
```

ESP-IDF 脚本还会在用户目录下载工具链和 Python 环境，需要联网并预留数 GB 空间。

## 2. 下载和安装 ESP-IDF

示例安装到 `~/esp/esp-idf`，以 `v5.4.2` 验证通用 Hello World。微雪安装页面的截图以 5.5.2 为例，但明确要求按开发板示例选择匹配版本；**目前未核实 V1/V2 示例与 5.4.2 的兼容性**。运行板级例程前先查看所选版本示例的 README、依赖和要求，再按需并存安装对应版本。先确认目录不存在；若已有 ESP-IDF，不要覆盖，改用其他路径或检查现有版本。

```bash
mkdir -p ~/esp
git clone -b v5.4.2 --recursive https://github.com/espressif/esp-idf.git ~/esp/esp-idf
cd ~/esp/esp-idf
./install.sh esp32s3
```

如果下载失败，检查网络后重新执行 `./install.sh esp32s3`。安装完成后，每次打开新终端需加载环境：

```bash
. ~/esp/esp-idf/export.sh
idf.py --version
```

确认输出 ESP-IDF 5.4.2。官方参考：[ESP-IDF macOS 入门指南](https://docs.espressif.com/projects/esp-idf/en/v5.4.2/esp32s3/get-started/index.html)。

## 3. 编译官方示例

将官方示例复制到本项目，避免修改框架自带文件。复制前如果 `apps/firmware/hello_world` 已存在，请先检查内容，避免覆盖。

```bash
cd /Users/liuzhe.x/coding/study-pet
mkdir -p apps/firmware
cp -R ~/esp/esp-idf/examples/get-started/hello_world apps/firmware/hello_world
cd apps/firmware/hello_world
idf.py set-target esp32s3
idf.py build
```

显示 `Project build complete` 或等效成功提示即表示编译通过；此步骤无需连接开发板。

## 4. 烧录和查看日志

使用支持数据传输的 USB 线连接开发板，确认连接到支持下载的 USB 口。查看端口：

```bash
ls /dev/cu.*
```

对比连接前后新增的端口，如 `/dev/cu.usbmodem...` 或 `/dev/cu.usbserial...`。将下面占位符替换为实际端口：

```bash
idf.py -p /dev/cu.你的端口 flash monitor
```

观察到芯片信息和 Hello world 日志即成功。退出监视器按 `Ctrl+]`。找不到端口时检查数据线、USB 口及开发板说明；部分 USB 转串口芯片可能需要驱动。下载失败时按照具体板子的说明进入下载模式，部分板需要按住 BOOT 再按 RESET。

## 5. 验证这块板的屏幕和触摸

通用 Hello World 只能验证编译、烧录和串口，不会点亮屏幕。按板背标签选择[微雪官方资源页面](https://docs.waveshare.net/ESP32-S3-Touch-LCD-2.8/Resources-And-Documents/)中的 V1 或 V2 示例包；V1 使用 CST328，V2 使用 CST3530。注意产品型号没有 B 或 C 后缀。

在示例包 `ESP-IDF` 目录查阅 README、版本和编译说明，并以匹配的 ESP-IDF 版本构建厂商的 `ESP32-S3-Touch-LCD-2.8-Test` 或相应板级测试例程。该例程涵盖 LVGL、显示、触摸及多个外设；按厂商说明逐项测试。微雪的 [ESP-IDF 页面](https://docs.waveshare.net/ESP32-S3-Touch-LCD-2.8/ESP-IDF/)有说明，页面中的通用截图版本不等于所有例程的兼容保证。如果触摸不响应，先核对板背版本和示例包，不要直接套用其他型号的引脚配置。

建议先依次验证：显示与触摸 → 2.4 GHz Wi-Fi → 音频（确认喇叭是否随板附带）→ 简单 LVGL 宠物页面。真实设备访问电脑服务时，`localhost` 指设备自身，需改用电脑的局域网地址；生产环境使用 HTTPS。后端和家长网页技术栈尚未确定，暂不必安装其运行时及数据库。
