# 账号与设备管理

本次补齐账号找回、昵称编辑、设备改名、归属变更和解绑重配。已有孩子、金币、任务、消费记录继续保留。

## 使用入口

- 登录页：忘记密码、重发验证邮件；邮箱未验证时可直接重发。发送后等待 60 秒再重试，实际发送还受 Supabase 的邮件限流影响。
- 家庭设备 → 账号与设置 → 修改密码：发送邮件到当前账号的注册邮箱。
- 密码邮件 → `/auth/reset-password`：验证链接后输入两遍新密码，可显示密码；保存成功后手动返回登录。此页面不自动进入家庭空间，回调凭据随即从地址栏移除，恢复会话仅保存在内存。
- 宝贝与小宠 → 编辑昵称：同时修改宝贝昵称、宠物昵称，金币不变。
- 家庭设备 → 每台设备的“管理”：修改设备名称、更换归属宝贝、解除家庭绑定。更换和解绑有二次确认；列表过期时先刷新再操作。
- 设备 → Settings → Device：显示云端设备名称和本机编号。解绑后联网同步，页面出现 `Enter family code`，可输入家庭码重新配对，再在手机端选择宝贝。

昵称在家长端展示；设备保持现有英文宠物界面。设备名称随钱包同步更新，过长名称在 Device 页滚动显示。

## 数据及同步规则

设备管理按登录家庭隔离；设备变更携带 `updated_at`，数据库锁定设备行并核对版本，避免多个页面互相覆盖。设备更换宝贝会刷新任务、商店和金币，并切换本机照顾规则的孩子归属。

购买菜单携带 `binding_version`；更换宝贝或解绑会更新该版本。购买事务锁定设备归属直到扣款完成，旧菜单或离线重试不能扣新宝贝的金币。旧固件的待确认订单只允许查询已完成的同孩子订单，不能发起新扣款。

解绑撤销旧凭据并保留设备行及历史。设备只有收到钱包接口明确的 401/403 才撤销本地绑定；超时、断网、服务异常不会清空绑定。用户再次输入家庭码时生成新随机凭据；配对响应丢失后重试沿用新凭据，防止重复创建设备。

离线设备会在下次联网同步后发现解绑。免费互动继续可用；付费互动必须服务端确认才播放。正常钱包约每 5 秒同步，等待家长选孩子约每 3 秒同步，均不含请求耗时。

## 部署顺序

1. 在 Supabase SQL Editor 执行 `supabase/migrations/20261118_account_device_management.sql`。这是增量迁移，不需要重跑旧 SQL。
2. Supabase Authentication → URL Configuration，保留已有地址，增加 `https://keep.1203.fyi/auth/reset-password`；Site URL 仍是 `https://keep.1203.fyi`。本次已在控制台补充并核实。
3. 提交并推送最新家长端/API 代码，让 Vercel 部署到 `https://keep.1203.fyi`。重新部署旧提交不会发布本地改动。
4. 烧录最新设备固件。新接口上线后，旧固件的新消费会被拒绝，需同步升级；旧的已完成订单仍可确认。新固件在旧 API 未提供归属版本时会暂时隐藏商店。

浏览器若仍显示旧页面，刷新并接受 PWA 更新。本次缓存版本为 v8。

## 验证

- 家长端：`cd apps/parent-h5 && node --test tests/*.test.cjs`；`pnpm --filter parent-h5 build`。
- 固件网络及 NVS 模拟：`apps/pet-device/tools/check_management.sh`；ESP-IDF 环境内执行 `idf.py -C apps/pet-device build`。
- 隔离数据库：加载 schema 和全部迁移后执行 `supabase/tests/account_device_management.sql`，以及现有商店、奖励和任务回归脚本。测试使用事务回滚，不应在生产库运行。
- 设备设置页：`tools/png_check/settings_check.c` 验证打开 Device 页时发生解绑，配对按钮可以及时出现。

本地验证采用模拟账号、邮件响应、隔离数据库，不发送真实测试邮件、不解绑真实设备。正式邮件的完整投递与新密码登录需在部署后用自己的账号验证。
