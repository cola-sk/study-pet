# 真实接口实施状态

家长端使用 Supabase 邮箱密码登录；家庭、孩子、设备配对、金币、家庭商店、任务模板与审批均通过服务端 API 访问数据库。设备使用独立凭据，支持配对、Wi-Fi 设置、余额同步、购买商品和今日任务打卡。

任务按家庭时区与模板频率按需生成。模板编辑、任务提交、审批和钱包记账均由服务端处理；设备提交的请求编号会持久化，用于超时、断网和重启后的安全重试。操作流程和升级步骤见 [设备打卡与任务闭环](./设备打卡与任务闭环.md)。商店和 Wi-Fi 的细节见 [设备商店与互动方案](./设备商店与互动方案.md) 与 [设备设置与 WiFi](./设备设置与WiFi.md)。

## 主要接口

- `POST /api/v1/family/bootstrap`：登录用户获取或初始化家庭。
- `GET|POST /api/v1/task-templates`、`PATCH|DELETE /api/v1/task-templates/{id}`：任务模板管理。
- `GET /api/v1/family/tasks`：家庭今日任务、待审批记录及模板。
- `POST /api/v1/family/tasks/{id}/review`：家长批准或退回任务。
- `GET /api/v1/device/tasks/today?offset=0`：设备读取关联孩子的今日任务，每页 10 条。
- `POST /api/v1/task-instances/{id}/submit`：设备提交或重试打卡。
- `GET /api/v1/wallet`、`GET /api/v1/device/shop`、`POST /api/v1/device/shop/purchase`：设备余额与家庭商店。

服务端使用 Supabase service role 凭据访问数据库，家长请求通过 Supabase Auth 验证，设备请求通过令牌摘要匹配已配对设备。数据库变更按 `supabase/migrations/` 文件名顺序执行；不要将服务端密钥、设备凭据或 Wi-Fi 密码提交到代码库。
